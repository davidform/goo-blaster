# 可選的 ChatGPT 構想簡報

不必先離開目前對話。若想用 ChatGPT 討論題材，可貼下面這段，再把結果帶回遊戲專案：

> 我要製作一款付費買斷手機遊戲。請把我的想法整理成可交給開發代理的一頁簡報：核心樂趣、目標玩家、主要操作、每局時長、勝負條件、成長與重玩理由、美術和聲音方向、離線需求，以及第一個可玩版本的必要範圍。請分清楚我已決定、你提出的建議、需要驗證的假設。不要擅自決定售價、引入廣告／付費隨機機制，或假設已獲得任何素材授權。最後列出 3 個能透過試玩驗證的問題。我的想法是：……

帶回來時只需說：「依遊戲工作室流程，將這份簡報做成第一個可玩版本。」附上簡報即可。代理仍須核對目前專案、平台能力與研究來源；簡報不取代程式、測試或發布授權。

不指定角色、關卡數與引擎也可以開始討論；永久 App 身分與正式商業決定在對應階段確認，避免在構想階段逼使用者回答一長串技術問題。
