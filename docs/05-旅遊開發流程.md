# 旅遊時也能改遊戲的流程

## 先決定：程式碼放哪裡才是「正本」

這是整件事最關鍵的一個決定，其他都是跟著它走。

| 方案 | 正本在哪 | 筆電要開嗎 | 要給我 GitHub 權限嗎 | 環節數 |
|---|---|---|---|---|
| **A. 我直接推** | GitHub | **不用** | 要（單一 repo 的 token） | 1 |
| **B. 筆電當中繼** | 你的筆電 | 要，而且要一直連著網路 | 不用 | 4 |
| **C. 全手動** | GitHub | 不用 | 不用 | 你自己上傳 |

### 為什麼旅遊情境下我建議 A

方案 B 需要同時成立四件事：筆電開機沒睡眠、網路沒斷、Claude 桌面版開著、
auto-push 在跑。任何一個斷掉，你人在國外都很難處理。
Windows 自動更新重開機、飯店 Wi-Fi 掉線、筆記型電腦闔蓋休眠 —— 這些都不罕見。

方案 A 只有一個環節：我在雲端改完直接 push，GitHub Actions 自動部署，
你手機打開網址就是新版。**筆電關機、放在家裡都無所謂。**

代價是要給我一組權限受限的 token（見下方）。

---

## 方案 A：給我一組 token，我直接推

1. GitHub 網頁 → 右上頭像 → **Settings** → 最下面 **Developer settings**
2. **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
3. 設定：
   - **Repository access**：選 **Only select repositories** → 只勾你的遊戲 repo
   - **Permissions** → Repository permissions → **Contents** 設為 **Read and write**
     （其他權限一律不要給）
   - **Expiration**：建議設 90 天或更短
4. 產生後把 token 貼給我，我就能 clone / commit / push

**安全性怎麼看**：這組 token 只能動那一個 repo 的檔案，不能碰你其他專案、
不能改帳號設定、不能刪 repo。想收回隨時可以在同一個頁面按 Revoke，即刻失效。
最壞情況的影響範圍就是那一個遊戲 repo。

---

## 方案 B：筆電當中繼（不用給我任何權限）

### 一次性設定

1. 在專案資料夾開命令列（在資料夾空白處按 Shift + 右鍵 → 在此開啟終端機）：

   ```
   git init
   git branch -M main
   git remote add origin https://github.com/你的帳號/你的repo.git
   git add -A
   git commit -m "first"
   git push -u origin main
   ```

   第一次 push 會跳出 GitHub 登入視窗，登入後 Windows 會幫你記住，之後不用再輸入。

2. 在 Claude 桌面版按 **Add folder**，把這個專案資料夾連進來，
   我才有辦法把改好的檔案寫進去。

### 每天啟動

雙擊 **`自動上傳GitHub.bat`**，讓那個黑視窗一直開著。之後：

```
我改檔案 → 4 秒後自動 commit + push → GitHub Actions 部署 → 手機重新整理
```

視窗會即時顯示每一次上傳。要停就按 Ctrl + C。

### 已經處理好的狀況

- **你在手機上用 GitHub 網頁改過檔案** → push 會被拒絕。腳本會自動
  `pull --rebase` 把遠端改動接進來再推一次，不會卡住。
- **網路暫時斷線** → 每 30 秒自動重試，不用管它。
- **存檔存到一半** → 有 4 秒的緩衝，等檔案不再變動才上傳。
- **暫存檔、log 檔** → 首次執行會自動建立 `.gitignore` 擋掉。

### 真正會卡住的狀況

同一個檔案你在手機和筆電上都改了、而且 git 沒辦法自動合併。
視窗會顯示「遠端與本地衝突，需要你手動處理」並停止重試，
等你回到電腦前處理。這種情況很少，前提是不要兩邊同時改同一個檔。

---

## 方案 C：全手動（零設定）

我把檔案給你 → 你在手機上下載 → GitHub 網頁版 → 進 repo →
`Add file` → `Upload files` → 選剛下載的檔案 → Commit。

手機瀏覽器可以做，大概 30 秒。缺點是每次都要做一遍。

---

## 不管選哪個方案，手機端都一樣

部署完成後網址是 `https://你的帳號.github.io/repo名/`

用手機瀏覽器打開 → 加到主畫面 → 之後點圖示就是全螢幕開啟，跟 App 一樣。
主畫面最下面有版本號，可以確認手機讀到的是不是最新版。
