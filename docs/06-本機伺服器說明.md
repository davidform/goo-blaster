# 在桌機跑、用手機測

## 最快的方式：區域網路直連

1. 把這個資料夾裡的檔案放在一起（`index.html` 要跟 `start-server.py` 同一層）
2. **雙擊 `啟動測試伺服器.bat`**
3. 黑色視窗會印出兩個網址，用**手機測的那個**（`http://192.168.x.x:8000`）
4. 手機連**同一個 Wi-Fi**，瀏覽器輸入那個網址

改完 `index.html` 之後，手機重新整理就是新版 —— 這個伺服器已經強制關閉快取，
不會發生「明明改了卻還是舊版」的狀況。

### 如果手機連不上

| 狀況 | 處理 |
|---|---|
| 一直轉圈連不上 | Windows 防火牆擋了。第一次執行時會跳提示，記得按「允許存取」。若已經按過拒絕：控制台 → Windows Defender 防火牆 → 允許應用程式 → 找到 Python → 勾選「私人網路」 |
| 手機和桌機不同網段 | 確認兩台連的是同一個 Wi-Fi（注意 2.4G / 5G 有時是不同 SSID，通常還是同一個網段，但公司或宿舍網路可能隔離） |
| 顯示連接埠被佔用 | 開命令列執行 `python start-server.py 8001`，改用 8001 |
| 咖啡廳／公司 Wi-Fi | 很多公網會開啟「用戶端隔離」，裝置之間互相看不到，這種情況只能改用 GitHub Pages |

### 這個方式的限制

- 桌機要開著，而且手機要在同一個 Wi-Fi（出門就不能測）
- 因為是 `http://` 不是 `https://`，**沒辦法「加到主畫面」變成全螢幕 App**
  （瀏覽器規定 PWA 安裝必須是安全連線）
- 沒辦法把連結傳給別人測

要突破這三點就要用 GitHub Pages（見另一個 zip 裡的 README）。
兩者不衝突：本機資料夾是原始碼，GitHub 是發布，一般開發都是兩個並用 ——
平常改東西用本機伺服器快速看，改到一個段落再 push 上去給手機/別人測。

## 檔案

| 檔案 | 用途 |
|---|---|
| `啟動測試伺服器.bat` | 雙擊就跑（會自動找 Python 或 Node） |
| `start-server.py` | 伺服器本體，零相依套件，只用 Python 標準函式庫 |
| `index.html` | 遊戲 |
| `manifest.webmanifest`、`icon-*.png` | PWA 設定（在 https 環境下才會生效） |
