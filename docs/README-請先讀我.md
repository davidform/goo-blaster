## 三種使用情境

### A. 我只想玩／給人試玩

用手機或電腦瀏覽器打開 `game/index.html` 就能玩。

但**手機請不要直接開下載的檔案** —— 用 `tools/啟動測試伺服器.bat` 起一個本機伺服器，
或部署到 GitHub Pages，然後用網址開。原因見 `docs/03` 第一項。

### B. 我要繼續開發

1. 把 `game/` 的內容放到你的專案資料夾
2. 需要本機測試 → 把 `tools/` 的檔案也放進去，雙擊 `啟動測試伺服器.bat`
3. 需要自動部署 → 照 `game/README.md` 設好 GitHub Pages，
   再雙擊 `自動上傳GitHub.bat` 讓它自動推

### C. 我要搬到另一個 Claude 帳號繼續

打開 **`交接提示詞.md`**，照裡面的步驟做。重點是：
**整包上傳，並且讓新的 AI 先讀 `docs/02` 和 `docs/03`。**

程式碼複製過去就有了，但「為什麼這樣寫」「哪些方案已經否決過」
「哪些 bug 修過、成因是什麼」不會跟著程式碼走。
沒有那兩份文件，新的對話會把已經走過的路再走一遍。

## 目前狀態一句話總結

遊戲本身完成度不錯（10 關、3 武器 + 3 進化、17 張機制型升級卡、7 種寶箱、
程序合成音樂與音效、過關花火），部署與自動化工具都備齊了，
**但卡在一個真機問題：使用者的手機上無法滑動移動角色。**

最可能的原因是他一直用 `file://` 直接開下載的 HTML 檔，
而不是透過網址開啟。這個假設**還沒被驗證**，驗證方式寫在 `docs/03`。
遊戲裡已經內建診斷顯示，能直接看出是哪一層出問題。
